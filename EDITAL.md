# Requisitos acadêmicos e atendimento pelo SIAM

Este documento registra como o SIAM atende às exigências da disciplina sem substituir o edital oficial ou orientações dos professores.

## Exigências

| Exigência | Atendimento |
|---|---|
| Aplicação desktop | Java 21 com interface Swing, já existente |
| Banco de dados | MySQL no MVP; banco online relacional na evolução |
| Autenticação | Login por e-mail/matrícula |
| Dois perfis | ADMIN e FISCAL |
| Três CRUDs | Usuários, postos, bombas e fiscalizações |
| Dashboard | Indicadores operacionais e analíticos |
| Vídeo | Demonstração do fluxo principal e da evolução |
| Trabalho em grupo | Responsabilidades registradas em branches e PRs |

## Ampliação acadêmica

O novo ciclo acrescenta levantamento de requisitos, casos de uso, análise de dados, API REST, armazenamento de imagens por serviço externo e proposta de aplicativo Kotlin. Essas ampliações não removem os requisitos originais.

## Evidências da entrega

- código versionado;
- documentação em Markdown;
- diagramas Mermaid;
- roteiro e vídeo demonstrativo;
- dados de teste não sensíveis;
- relatório de testes e limitações.

Prazos e critérios de avaliação devem ser confirmados com os professores responsáveis.
